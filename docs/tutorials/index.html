01 / GET SET UP1:00

Install SEARCH-IN

Prepare a new PC, get the required runtimes, and finish Setup.

Labeled setup simulationBEGINNER
Follow the steps / jump to a moment
  1. Prepare a new Windows PC.
  2. Get the .NET Desktop Runtime if it is missing.
  3. Offline? Bring both standalone Microsoft runtime installers first.
  4. Install WebView2 for the embedded preview.
  5. Choose where SEARCH-IN is installed.
  6. Finish, then explore the Content Indexer.

02 / BUILD YOUR INDEX1:00

Your first index & optional AI

Choose a folder, extract locally, and review what still needs OCR.

Real app / no AI requestLOCAL FIRST
Follow the steps / jump to a moment
  1. Tools > Open Content Indexer.
  2. Check your folder. Change selects a different scope.
  3. Select Start to extract text locally.
  4. Review the files that remain AI Pending.
  5. Optional: select a vision-capable provider and add your own key.
  6. Save encrypted credentials. AI runs need your approval.

03 / FIND THE FILE1:00

Find files & choose folders

Search names and extensions. Narrow your search to the right place.

Real app demonstrationFILES MODE
Follow the steps / jump to a moment
  1. Type part of a filename.
  2. Narrow by an extension, such as .pdf.
  3. Select a result once to preview.
  4. File > Open Directory limits the search location.
  5. Clear the scope to restore a broader search.
  6. Enable Match Path to search folder names too.

04 / FIND THE WORDS1:00

Search inside files

Read Match snippets and navigate visible matches in the preview.

Real app demonstrationIN-FILE MODE
Follow the steps / jump to a moment
  1. In In-File, type text from inside an indexed document.
  2. Read the Match snippets to spot the right result.
  3. Select the result to see visible matches highlighted.
  4. Use the find arrows to move between matches.
  5. Scroll or change pages without opening the source.
  6. Try a distinctive phrase for fewer results.
